# 缺料窗口核算结果 — 验收演练工作记录

资料性质：这是虚构项目数据上的实际计算演练，用于测试产品闭环，不声称已经接洽或审核真实供应商。以下计算由本次演练执行者根据给定输入完成。

## 输入与口径
材料M用于海外工厂订单，每件产品消耗1单位M，无替代料。2026-10-05期初可用库存70单位，已排除隔离库存。需求按日末扣减，到货在当日开工前已经完成验收并可用。未满足需求作为积欠跨日延续，不取消、不将积欠自动清零。
10月5日需求150、确认到货0；10月6日需求100、确认到货120；10月7日需求80、确认到货100；10月8日需求20、确认到货60。首批补货10月1日下单，承诺10月6日完成到货验收，可用交期窗口为5个日历日。

## 我完成的逐期计算
采用带符号的净结余：上日净结余＋本日可用到货－本日需求。负值代表累计未满足需求，而非可供实物库存。
10月5日：70＋0－150＝−80，累计缺口80。
10月6日：−80＋120－100＝−60，累计缺口60。
10月7日：−60＋100－80＝−40，累计缺口40。
10月8日：−40＋60－20＝0，积欠清零。
因此在该日粒度口径下，最早缺料日是10月5日，最大累计缺口80单位。10月5、6、7日末均存在缺口，10月8日末解除暴露。日内停线的精确小时数尚需工单消耗时点，不能由日末余额冒充计算。

## 我复核的交期敏感性
我将首批120单位的可用交期延迟1天，由10月6日改到10月7日，其他需求及到货不变。重新计算：10月5日−80；10月6日−80＋0－100＝−180；10月7日−180＋220－80＝−40；10月8日−40＋60－20＝0。最大缺口从80升至180，增加100；最早暴露仍为10月5日，按日末评估的解除日仍为10月8日。不能因为最终恢复日不变，就说交期延迟没有影响。
我也复核了首批120单位提前1天至10月5日的情况：10月5日70＋120－150＝40；10月6日40＋0－100＝−60；10月7日−60＋100－80＝−40；10月8日−40＋60－20＝0。最早缺料变为10月6日，比基线晚1天；最大缺口降为60，减少20，但不能完全消除暴露。

## 订单影响追溯
按先到期先分配，订单O1在10月5日需150，基线先满足70，剩余80由10月6日到货补齐；10月6日订单O2需100，先扣除前欠80后只能满足40，剩余60延至10月7日；10月7日订单O3需80，先补O2的60后只能满足40，剩余40延至10月8日；10月8日到货60先补O3的40，再满足当日订单O4的20。此分配与每日累计缺口80、60、40、0交叉核对一致。

结论：首批补货必须优先保证10月6日可用。若延迟到10月7日，需要额外覆盖10月6日增加的100单位积欠暴露。本记录证明本次给定数据的核算过程；真实供应商承诺及交付执行仍需业务人员核实。
