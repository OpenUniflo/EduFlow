## Git 与目录规则

| 内容 | 位置与规则 |
| --- | --- |
| 现行架构、契约、ADR、运维手册 | `docs/architecture/`、相关领域文档；继续跟踪 |
| 当前操作说明、交付摘要、未解决问题 | 本目录；继续跟踪 |
| 正式回归源码、测试服务和可复用输入 | `tests/`、`fixtures/`；继续跟踪 |
| 数据库版本历史 | `supabase/migrations/`；继续跟踪，不改写已应用迁移 |
| 阶段实施经过、候选/复验明细、工程台账、旧报告、迁移索引 | 本地 `artifacts/archive/`；不跟踪 |
| 新运行结果与缓存 | `artifacts/` 等忽略目录，不写回正式文档 |
| 私有账号、环境与本机进程配置 | `.acceptance/`、本机环境文件；忽略且不因整理清空 |

已完成阶段的计划应在收尾时归档；仍有当前执行用途的活动计划可保留，不能仅因名称带阶段编号就删除。

阶段验收脚本已撤掉；可复用能力已进入正式测试。`pnpm test:workflow` 是固定离线入口，`pnpm workflow:check-layout` 只检查当前维护结构，不依赖历史映射或旧验收产物。测试发现范围也排除了历史归档。
