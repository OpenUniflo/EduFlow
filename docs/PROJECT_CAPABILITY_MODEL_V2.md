## Frozen V2 semantics and implementation decisions

- Project candidate space and selected route are separate pure computations. Inputs are visible active IDs, factual prerequisite DTOs with strength, current satisfied IDs, and explicit curriculum order. No React, Supabase, or feature imports in shared core.
- All supplied active prerequisite cycles fail explicitly. Compute V2.1 hard-AND current support in topological order: satisfied nodes are boundaries; otherwise every hard parent must have current support and at least one real incoming edge must lead from supported knowledge. Immediate frontier consists of satisfied nodes and nodes whose hard parents are currently satisfied (including no-hard-parent nodes). V2.1 candidate relevance and current support supersede the original V2 eventual-learnability candidate rule; see the current-gap section above. Every target remains visible, and retained target-to-target facts remain visible even without a current origin. Retain supplied hard edges from missing endpoints as unavailable support, never silently convert them into roots. No path enumeration. The authenticated visible-graph RLS boundary remains authoritative: missing-endpoint checks cover supplied edges (including visible but inactive endpoints), not invisible facts hidden by RLS.
- Default route starts at nonexcluded targets and walks hard ancestors, stopping at satisfied boundary nodes. Include is allowed only inside candidate space and adds the same hard closure. Exclude is checked before satisfaction and prevents any use of that identity. An acquired boundary does not require relearning its ancestors. All targets excluded is a legal empty commitment, with explicitly included nodes still honored.
- Conflicts carry kind, root target/include identity, excluded or unavailable prerequisite identity and constraint identity. No frontend inference. Selected edges include factual hard/soft edges whose endpoints are selected; deterministic Kahn order honors those edges and curriculum priority, then stable ID. Reachability/closure are linear; deterministic queue ordering adds sorting cost, not path enumeration.
- Saved snapshots include IDs, strengths, order, effective targets and titles at save time. Current execution is recomputed from active constraints and current inputs. Fingerprint scope is the reverse structural closure of all targets and constraint IDs, computed without consulting current state; it includes structural IDs/edges/strengths/curriculum ordering, never user state, titles, colors, or draft presentation. Invalid current constraints produce explicit conflicts, never mutation of history.
