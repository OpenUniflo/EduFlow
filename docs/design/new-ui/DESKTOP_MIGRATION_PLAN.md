## 3. 迁移顺序（每一步都可独立验收与回滚）

**P0 · 基础设施**（0 与 1–4 互不依赖，可并行）
0. 产品内容移出仓库：按 §8 执行（8-1、8-2 先做，8-3、8-4 在其后）。
1. `src/shared/styles/tokens.css` 与玻璃滤镜组件；减少透明度与 Safari 回退。设计侧的 `system/tokens.css` 作用于画板（`.ef` 作用域，含 `min-height:960px` 等画板专用规则），不能直接复制：新增一个同步脚本，把令牌转换成 `:root` 作用域、去掉画板专用规则后写入 `src/shared/styles/tokens.css`，并提供 `--check` 模式，在令牌与设计源不一致时失败。
2. 基础组件：按钮、输入框、胶囊/上下文胶囊、头像与人物色环、对象外壳四种尺寸、对话气泡与卡片（事件行 / S 480 / L 满宽）、首页输入框、账户菜单。
3. 功能预览机制：预览数据源契约（与真实仓储同接口）、`src/demo/preview/` 示例数据、`src/app` 注入、统一的「预览 · 示例数据」标识组件。
4. 规格检查：`lint.py` 只检查设计稿的 `.dc.html`，现有 `pnpm lint` 只跑 ESLint（`ts`/`tsx`）。新增 `pnpm lint:css`（stylelint 或等价脚本），并入 `pnpm lint`：新样式文件（`legacy.css` / `product.css` 之外）不得出现规格外的字号、颜色、圆角、阴影，同时运行第 1 步的令牌一致性检查。尚未迁移页面的旧样式文件列入豁免基线，每迁移一页就把该页样式移出豁免。

**P1 · 外壳与导航**：左侧导航栏、账户菜单、路由表与旧路由重定向、`/messages` 下线。

**P2 · 首页**：对话工作台、卡片类型、我的面板、复杂微学习侧面板、实践三态（草稿/确认/结果）与「提交给」选择、长文本/加载中边界态。

**P3 · 档案**：单一星图 + 我的范围标记 + 缩放、课程浮层与搜索、课程聚焦、助手寻找与课程创建简报、未登录态；社交部分以预览接入（社交入口图标、人与分享浮窗、对比）。（已完成；交互按 §10 返工为 P3R。）

**P4 · 课程沉浸（three.js）**：ELK 坐标 → three.js 场景 + DOM 叠加；技能树、实训影子层换层、竖向路线、语义缩放、能力模型 3D 旋转、路线光带、压平为 2D 路线编辑；原位放大进入/退出转场。three.js 按需加载。（已完成；交互按 §10 返工为 P4R。）

**P3R · 档案返工**：按 §10.1–10.5 把档案改为 three.js 3D 星图与三种布局状态（默认 / 以人为中心 / 课程平面）、地图式分层、选中高亮、面板规则。

**P4R · 课程页返工**：按 §10.6–10.8 改为「课程树 / 路线」两个视图、技能树与实训树倒影切换、默认路线光带、选中高亮、节点侧边栏、闯关式路线。P3R 与 P4R 共用同一套节点移动动画与 three.js 场景，P3R 先做。

## 10. 档案与课程页交互规格（2026-10-31，依据交互演示第二版）

来源：2026-10-31 的走查与产品负责人意见，已在交互演示第二版（§0）中实现并确认。本节与设计稿冲突时以本节为准；对应规则已同步修改（AGENTS.md「Product-wide Invariants」、`docs/rules/knowledge-atlas.md`、`docs/rules/course.md`、`docs/rules/frontend-ui.md`）。

### 10.1 档案是真 3D 星图

- 用 three.js 渲染：左键拖拽可 360° 自由旋转，滚轮缩放，右键 / 双指平移，松手有惯性。不再使用 2D Canvas。课程页（§10.7）使用完全相同的操作：左键拖拽旋转、滚轮 / 双指缩放、右键或 Shift+拖拽平移、松手有惯性。
- 默认布局是一份结果固定的 3D 力导布局：哪些点相连只由真实关系决定，同领域的知识之间再加一份弱吸引，让每个领域各自成团、团与团之间稍微分开（「未分类」也单独成一团），跨领域的真实连线照常画出。领域只影响位置，不制造、不删除任何连线；不用章节、主题等锚点。（2026-10-31 已定）
- 同屏领域颜色互不相同：只给有知识的领域分配颜色，超过 6 个时扩充色板。
- 节点大小随镜头距离变化：近看时是带体积的发光球，外圈状态环清楚可辨（照演示）；远看时退为小点。
- 节点用批量绘制的发光点，连线用细线；节点标签只在近处出现，按屏幕位置做碰撞裁剪，任何时候不重叠。

### 10.2 像地图一样分层

| 镜头距离 | 显示 | 类比 |
|---|---|---|
| 远 | 每个领域一团带领域色的柔光区域，标「领域名 · 知识数」；领域之间画按跨领域连线数加粗的汇总线；节点只是小点，没有标签 | 国家 / 省 |
| 中 | 领域内的主题小团，柔光更小，标主题名 | 城市 |
| 近 | 单个知识点与标签 | 街道 |

- 三层之间按距离渐变过渡，不会突然切换，也不重排。左下角显示当前层级（领域 / 主题 / 知识）。
- 「主题」是由每个领域内的真实关系计算出的分组（确定、只用于显示、不入库、不是知识节点、不参与布局），以组内最核心的知识命名。（2026-10-31 已定，可推翻；如果命名效果不好，中层可以退为只显示无名柔光。）
- 选中某人时，各层的标签同时显示覆盖情况，如「检索与知识 · 我 8 · 阿青 16 / 40」。

### 10.3 人物胶囊栏与面板（左上角）

- 结构：`[人头图标] | [我] [关注的人…] [+]`。
- **人头图标**：打开 / 关闭「人与分享」面板（我关注的人：查看、对比；谁能看到我的档案；生成可撤销的分享链接）。不是个人面板。
- **点某人的头像**（我或别人）：打开这个人的面板（我：我的知识数、在学、课程列表、各领域覆盖、最近学习；别人：公开知识、共同课程、各领域覆盖、「与我对比」），同时把星图切换成以这个人为中心的布局（§10.4）。
- 再点同一个头像、点空白处或按 Esc：回到默认布局，面板关闭。按住 Shift 点第二个人：两人对比。
- 面板右上角有收起按钮，收起后留一个小条，点开恢复；面板**只由用户收起或打开，永远不随缩放、聚焦或选课程自动变化**。
- 删除：右下角「定位到我」按钮、「高亮我的」开关、常驻的「我的知识」大框。
- 右下角只保留：缩小、缩放百分比（放大变大、缩小变小）、放大、复位视角。

### 10.4 以人为中心的布局

- 这个人的知识被拉到中心，聚成紧凑的核心，外圈用人物色环标记；其他知识按与核心的关系远近一圈圈向外排（一步相连在内圈，越远越外），尽量保持在默认布局中的方向，所以领域依然可辨。
- 非这个人的知识保持可见（约 50% 亮度），连线更淡；缩小后能直接看出「我的核心在全局里的位置和覆盖面」。
- 近看时知识名称只显示这些人的核心知识（对比时为并集）；其他节点只画点，悬停、选中及选中节点的一步邻居例外。名称框宽度按实际字体测量（含色点与边距），短名称必须完整显示，只有超过约 260px 才省略、悬停显示全名。核心名称优先但不强制：只贴在自己节点的上 / 右 / 下 / 左，放不下就不显示，不得挪到远处空位。档案所有视图（默认、以人为中心、课程平面）的名称都在旋转与缩放时冻结（集合不变、只随节点移动），停止约 250ms 后重算，变化 200ms 淡入淡出，一个节点最多一个名称（同 §10.10）。人物色环随距离放大但有屏幕尺寸上限（外径不超过约 60px，线宽固定）。
- 布局是「图结构 + 人物集合」的确定函数，可缓存；切换时所有节点平滑移动（600ms），镜头同时调整。形成之后在这个布局上自由旋转、缩放，不再重排。
- 两人对比：两人知识的并集作为核心，节点外圈按人物色分段，面板显示两人各领域覆盖。
- 别人的知识只使用服务端授权给当前用户的数据；没有社交后端前按功能预览接入（§2）。

### 10.5 档案里的选中与课程聚焦

- **点一个知识**：它本身、相连的边和一步内的邻居高亮并显示标签，其他节点降到约 20% 亮度；右侧滑出详情侧边栏（所属领域与主题、谁已学、相邻知识、出现在哪些课程），画面左移让出侧边栏。点空白处或按 Esc 取消。悬停只做轻量预览（标签 + 相连边）。
- **选课程**（从个人面板的课程列表）：
  - 这门课的知识（就是星图里的同一批节点）从原位置移动到一个正对镜头的平面上，按课程的 ELK 坐标排开；每章一个半透明章节区域，章节标题在区域上方。**不另外叠一层平面图。**
  - 其余星图留在平面后方，约 40% 亮度；课程知识连向课程外知识的边保持淡淡可见。
  - 悬停课程里的某个知识：它连向全局的边、以及连到的全局知识一起变亮并显示名称。
  - 点课程里的某个知识：与档案里普通选中相同——高亮它与一步邻居（含课程外知识）并显示它们的名称，平面上其余卡片与节点变淡且不显示名称（选中期间不按距离显示名称），选中标记不画大圆圈，右侧滑出知识详情，详情主按钮为「在课程中打开」。选中时平面不缩小，只平移让选中卡片可见。课程平面可自由旋转，显示与交互按 §10.10。
  - 顶部出现课程条：课程名、进度、「点空白处返回星图」提示、「进入课程」。
  - 个人面板不关闭；平面自动缩放并让到面板右侧，完整可见。
  - 点空白处或按 Esc：有选中时先取消选中；没有选中时课程节点飞回原位，恢复星图。只有点课程条的「进入课程」或详情里的「在课程中打开」才进入课程页（同一场景继续，不重新加载）。（2026-10-31 修订：点课程里的知识不再直接进入课程。）

### 10.6 课程页：两个视图

- 顶部只有「课程树」「路线」两个标签。技能树、实训树、能力模型不再是分开的标签页。
- 左上：「← 档案」（回到 §10.5 的课程平面）、课程名、已学数与当前知识。底部：图例（已学 / 在学 / 待学，合计等于课程知识数；当前、目标为标记）。

### 10.7 「课程树」视图

- **技能树与实训树互为倒影**（照旧版课程图的叠卡效果）：每张知识卡正下方叠着它对应的实践卡，**与前景卡同尺寸**（向右下错开约 14px、虚线、半透明），露出的边缘带身份条（实践编号与名称），不得缩成一个点；没有对应实践的位置显示虚线的「暂无对应实训」。点「切换到实训树」：两层在约 420ms 内交叉换位（前层退后变淡、后层前移显出内容，两层偏移连续插值，照演示），实践卡变成实体、知识卡变成同尺寸的倒影；再点切回；系统「减少动态效果」时直接切换。切换不重排、不改镜头；打开的详情跟随切换到对应侧面。
- **项目能力模型在后方**：课程外的前置能力放在支撑它的课程知识正后方更深的平面；能力层**默认存在、没有开关按钮**：正面时被知识层挡住，拖拽旋转后自然显现，虚线连到前面的知识；能力节点在任何角度都只显示为点（不以卡片出现，名称按 §10.10 的名称规则挂出），不按角度隐藏；看得见的能力点就能点选、能显示名称。能力放在它所支撑课程知识的正后方（支撑多个时取其中心后方），按离课程知识的步数分成两到三个靠得较近的后层，不得聚到画面一角，也不得拉成一条长斜线。**能力模型的范围**：从已具备能力出发、到达课程知识的所有路径上的节点和边（按现有模型计算，不多不少），边常态清楚可见（按屏幕像素定宽约 1.5px 的实线，能力连线色约 55–60% 不透明；选中时点亮的边约 2.5px，未关联的保留约 18%）。**课程页配色**（课程卡片、能力模型、状态条图例统一；档案等其他页面的学习状态色与领域色不变）：绿 = 已具备，蓝 = 待学目标（尚未学会的课程知识），灰 = 待学的中间能力；「在学」只加外圈标记，不改主色。正面时状态栏有一行轻提示「拖动旋转可查看 N 个前置能力」。可 360° 自由旋转（不限角度）；旋转时的显示与交互按 §10.10。工具条只有「回正面」。
- **我的路线默认显示**：光带就是当前路线，按执行顺序依次经过路线上的每个节点（含没有卡片的能力节点与中间节点；启用个人路线只是让路线多出这些节点），锚点取节点实际绘制位置，与步骤序号无关。光带画在卡片与平面之上、页面浮层之下：一条常驻的柔光淡轨迹（柔光底 + 细芯，与普通连线明显区分）+ 2～3 段错开出发的浅色发光彗星（头亮尾渐隐），按路程匀速约每秒一步循环游走，经过卡片时文字仍可读；减少动态效果时只显示淡轨迹。技能树与实训树显示同一条路线，换层时随节点位置一起移动。**只有这一种样式**——已采用个人路线与按课程顺序的默认路线显示相同，区别只在状态栏文字（「按课程顺序」）；知识卡左侧标步骤序号；当前步只体现在节点自身（正面：卡片主色描边 +「当前」徽标；斜面：带主色外圈的点），不再有浮动的「你在这里」标签。工具条里可关闭。
- **点一个节点**（知识 / 实践 / 前置能力）：进入「只看关联」，与档案相同取**一步关联**——它的前后依赖各一步、路线上前后一步、直接支撑它（或它直接支撑）的能力，连同相连的边保持高亮并显示名称；关联节点始终画在真实位置，不因角度隐藏（在平面后面的被前面卡片自然遮挡或透出，转过去即可看清）；变淡的节点仍可点击，点击即切换选中；高亮只用描边与透明度，不抬起、不放大卡片，点亮的边为清楚的实线；其余节点与边变淡（约 20%）且不显示名称，按距离显示名称与环绕标注在选中期间停用；知识卡与它的实训倒影是同一节点的两面，选中一面时另一面只随之保持正常亮度，不另外高亮、不挂名称（关联实践在详情里列出）；不在路线上的选中会让路线光带变淡。右侧直接滑出详情侧边栏（不再是小卡片）：知识显示学什么、关联实践、前置、我的学习证据和主按钮；实践显示要做什么、覆盖的知识、提交给谁；前置能力显示是否已掌握、支撑哪些知识。侧边栏里的条目可以点击跳转。点空白处或按 Esc 关闭。
- **近看**：卡片放大到一定程度时显示行动行（微学习用时、实践编号、资料页码）。章节标题、卡片、标签任何时候不重叠。
- **调整路线**：同一批节点压平成三列（已获得 → 中间能力 → 目标，列内按依赖深度排列、过多时分子列），当前路线为主色流动光带（编辑时变淡作对照），编辑后的预览路线为琥珀色流动光带，两条同时可见；采用后预览光带过渡为当前光带，取消则消失；必须经过 / 不经过、预览、采用沿用现有服务端校验。点「完成」回到 3D。

- **视觉照演示（2026-10-31 补充）**：知识卡约 176px 宽、单行名称 + 状态点，当前 / 目标为右上角小徽标，步骤序号是贴在卡片左边缘的实心圆；实践卡左侧有实践色竖条和编号；能力卡比知识卡小一号（约 150px）、虚线边框。倒影层始终保持虚线、半透明、只露边缘：选中时只加亮描边，不变成白底实体卡。实训树每个知识位置只放一张对应实践卡，一个知识对应多个实践时合成一张「实践组 · N 项」，不重复画同一张卡。行动行只在近看时占位，远看卡片不留空白。缩小（正面）与旋转（斜面）共用同一套简化阶段，按卡片屏幕尺寸决定：完整卡片 → 名称胶囊（序号并入胶囊左侧）→ 每个知识一个点（按状态着色，当前步呼吸外圈，序号仅悬停显示，倒影在此阶段隐藏）；任何时候一个知识只有一个标记。（旋转时的卡片简化见 §10.10，取代此前「重叠超过 12% 收成点」的规则。）

### 10.10 倾斜平面的显示与交互（课程树、档案课程平面，2026-10-31，依据演示第三至五版）

适用于课程页「课程树」和档案的课程平面。**两处共用同一套交互实现**（镜头参数与操作、缩放工具条、悬停样式、选中规则、名称规则、点选），各自只保留特有部分（档案：人物、领域、课程平面、全局星图；课程页：技能 / 实训两层、能力层、路线光带、步骤序号）。共用约定：离正面 <15° 松手回正；双击空白回正面、双击卡片聚焦；缩放工具条按钮顺序、名称与「适配全图」一致；悬停在卡片阶段只加亮卡片描边、点阶段才在点外画圈，不在卡片文字上画圈；场景上不挂浏览器原生提示框；一个节点同一时刻最多一个名称，卡片或胶囊上已写名字时不另挂。档案课程平面与课程页用同一套课程配色（绿已具备、蓝待学目标、灰中间能力）。原则：**卡片贴在平面上表达空间关系；点选与名称由始终正对屏幕的标记负责；斜面时显示哪些名称由距离和操作决定，不由几何挤压的结果决定。**

- **卡片随平面倾斜**：知识卡、倒影卡、能力卡、章节面板与章节标题是平面上的 3D 面板（three.js CSS3DRenderer），随所在层一起旋转并透视变窄；与 WebGL（节点、连线、光带）共用同一相机。
- **按角度连续简化**（θ 为视线与平面法线的夹角，连续插值，不做阈值切换）：
  - θ ≤ 35°：完整卡片；章节名贴在平面各章上沿。
  - 35°–55°：卡片淡出为正对屏幕的点，名称以挂在点旁的标签显示（放得下的都显示，按碰撞避让，不截成几个字母）；行动行、状态行、倒影文字随卡片淡尽；章节名淡出。（2026-10-31 P4R4 调整：大课程在此角度用倾斜胶囊会互相压叠、名称被截断。）
  - 约 55°–65°：名称从「放得下的都显示」平滑过渡到下条的按距离显示，淡入淡出，不闪现。
  - 65° 以上与背面：只有正对屏幕的正圆点（含状态外圈）与按下条显示的名称；背面不出现任何镜像文字。
- **斜面的名称**：
  - 选中、悬停的节点总是显示名称。
  - 按距离自动显示：节点屏幕直径超过约 14px 时进入候选，最多约 8 个，优先级选中 > 当前 > 路线上 > 其余，同级按离镜头距离与 id 稳定排序；近的完全不透明、远的约 60%；名称在节点的上 / 右 / 下 / 左中选不重叠的位置。
  - 防闪烁：出现与消失用不同门槛（>14px 出现、<10px 消失）；拖拽与缩放过程中名称集合冻结、只随节点移动，停止约 250ms 后才重新计算，变化用 200ms 淡入淡出。
  - 一个节点同一时刻最多一个名称（统一登记，任何来源不得重复）；名称只在自身节点的上 / 右 / 下 / 左选位，放不下就不显示，不得挪到远处空位。
  - 普通悬停只为该节点补上名称（不额外展开邻居名称；档案课程平面另加最多 3 个最近的跨课程关联知识名称），其他按距离显示的名称照常保留。
  - 环绕标注只在分不清时出现：光标点选半径（22px）内有 ≥3 个节点且停留约 400ms；出现时其他按距离显示的名称淡出，悬停节点名称并入列表；列表放在平面包围框外侧、不压节点，最多 6 项，引线按纵向顺序不交叉；移开或开始拖拽即消失。
  - 章节名不常驻：斜面时只在悬停某章区域时显示该章名称并轻微加亮章节面板。
- **点选**：所有节点（课程知识、倒影实践、能力、档案星点）统一按屏幕空间最近点选，命中半径至少 22px，与绘制大小无关；完整卡片、胶囊、点、被遮挡与背面的节点都能点；重叠取离镜头最近者。点选只选中并打开详情，**镜头不动**（不自动转正）。
- **选中永远可见（x-ray）**：选中标记为节点本身描边加亮（卡片阶段为卡片描边），不画盖住卡片文字的大圆圈；被前面平面挡住时，选中节点及其连线画在最上层，显示不超过节点尺寸的小外圈与名称，挡在前面的卡片局部变淡。详情里「定位」按钮只平移并拉近，让该节点到画面中央，不改变旋转角度。
- **镜头**：左键拖拽旋转（360°，不限角度），滚轮 / 双指缩放，右键或 Shift+拖拽平移旋转中心；平移范围包住知识层、倒影层与能力层；双击卡片把旋转中心移到该卡，双击空白回正面；离正面 <15° 松手自动回正，其他角度不吸附。
- **能力层清单**：没有按钮；转到能力层可见（约 35° 以上）时右侧自动出现窄条「前置能力 · N」，点开为清单（搜索，按已掌握 / 未掌握分组，显示支撑的课程知识数，经其他能力间接支撑的显示「直接 n · 间接 m」，不得显示 0），回到正面自动收起；悬停清单项高亮场景中对应节点，点击选中（镜头不动，靠 x-ray 显示）。选中能力节点时它与其支撑的课程知识保持高亮、其余变淡。清单与详情侧边栏不重叠。
- **连线分层**：能力模型的边平时为按像素定宽约 1.5px 的实线（约 55–60% 不透明），选中时点亮与选中节点一步相连的边，其余变淡；课程内依赖为实线；档案课程平面连向全局的线平时淡、悬停 / 选中时亮。
