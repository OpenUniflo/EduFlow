依据：设计稿最新版（见 §0）、[`AGENTS_RULE_CHANGES.md`](AGENTS_RULE_CHANGES.md)、2026-10-29 的产品决定：

## 3. 迁移顺序（每一步都可独立验收与回滚）

## 4. 每页验收标准

- 与对应画板在 1440×960 下逐屏对照（结构、字号、间距、状态）。
- 新样式只用 tokens；该页不再引用 `legacy.css` / `product.css` 中的旧规则，并删除只服务于该页的旧规则。
- `pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm build` 通过；页面无运行时错误。
- 预览区域有标识、不写入、不混入真实数据。
- 键盘可达、焦点可见、减少动态效果时有替代。
- Vercel Function 数量不增加：当前 `api/` 顶层 11 个（9 TS + 2 Python），Vercel Hobby 上限 12 个（见 `docs/rules/platform.md`），剩余 1 个留给 Assistant 边界。

## 5. 风险

- **three.js 场景里的 DOM 叠加**：节点多时的同步开销需要先做原型测量（目标：课程 35 节点 + 能力 11 节点旋转时 60fps）。
- **玻璃材质**：大面积 backdrop-filter 的性能与 Safari 回退需要在 P0 先验证。
- **旧样式体量**：`legacy.css` + `product.css` 约 12,200 行，逐页删除时要注意被多页共用的规则。
- **规则**：新版 UI 的规则已合入 `AGENTS.md` 与 `docs/rules/`（2026-10-30）。
- **以人为中心的布局计算**：每个人（或对比组合）一份布局，按「结构版本 + 人物集合」缓存；上千节点时放到 Web Worker 计算，切换时先用默认布局占位再动画过去。
- **档案星图规模**：现有 `KnowledgeAtlasScene` 每个节点单独绘制、力导在主线程计算；全局知识到上千节点时需改为批量绘制、后台或缓存布局、远景简化为点。

## 6. 实践简化（2026-10-30 决定）

- 实践只有一种类型（2026-10-30 再次确认）：问题描述、实现方式、一次提交。提交方式两种：从「作品」选择工作流（系统支持的格式，提交时冻结），或上传文件 / 链接。
- 问答类检查属于微学习，不再作为实践。
- 实践可以「新建工作流并关联」或关联已有作品；提交时冻结所关联作品的某个版本，另可附文件 / 链接与备注。实践只由评估者（教师或 AI）评估，不再有规则判分。
- 现有数据：`answer` 类实践直接删除；`code`、`trace` 改为文件上传实践。代码侧 `AssignmentAuthoringEditor`、`AssignmentExperiencePage` 随 P2 调整；内容侧不改仓库里的种子（P0 后已不存在）：本地在导出快照时已删除全部 22 个 `answer` 类实践（§8-1；黄金课程 37 个实践中默认类型即 `answer`），托管环境在 P2 部署时按 §8-6 处理。托管环境上已有 `code` / `trace` 实践如何转换见 §9。

## 10. 档案与课程页交互规格（2026-10-31，依据交互演示第二版）

来源：2026-10-31 的走查与产品负责人意见，已在交互演示第二版（§0）中实现并确认。本节与设计稿冲突时以本节为准；对应规则已同步修改（AGENTS.md「Product-wide Invariants」、`docs/rules/knowledge-atlas.md`、`docs/rules/course.md`、`docs/rules/frontend-ui.md`）。

### 10.1 档案是真 3D 星图

- 用 three.js 渲染：左键拖拽可 360° 自由旋转，滚轮缩放，右键 / 双指平移，松手有惯性。不再使用 2D Canvas。
- 默认布局是一份由真实关系驱动、结果固定的 3D 力导布局，不用领域、章节等锚点（演示里的锚点只为生成示例数据，正式实现不得照搬）。
- 节点用批量绘制的发光点，连线用细线；节点标签只在近处出现，按屏幕位置做碰撞裁剪，任何时候不重叠。

### 10.2 像地图一样分层

| 镜头距离 | 显示 | 类比 |
|---|---|---|
| 远 | 每个领域一团带领域色的柔光区域，标「领域名 · 知识数」；领域之间画按跨领域连线数加粗的汇总线；节点只是小点，没有标签 | 国家 / 省 |
| 中 | 领域内的主题小团，柔光更小，标主题名 | 城市 |
| 近 | 单个知识点与标签 | 街道 |

- 三层之间按距离渐变过渡，不会突然切换，也不重排。左下角显示当前层级（领域 / 主题 / 知识）。
- 「主题」是由每个领域内的真实关系计算出的分组（确定、只用于显示、不入库、不是知识节点、不参与布局），以组内最核心的知识命名。（2026-10-31 已定，可推翻；如果命名效果不好，中层可以退为只显示无名柔光。）
- 选中某人时，各层的标签同时显示覆盖情况，如「检索与知识 · 我 8 · 阿青 16 / 40」。

### 10.3 人物胶囊栏与面板（左上角）

- 结构：`[人头图标] | [我] [关注的人…] [+]`。
- **人头图标**：打开 / 关闭「人与分享」面板（我关注的人：查看、对比；谁能看到我的档案；生成可撤销的分享链接）。不是个人面板。
- **点某人的头像**（我或别人）：打开这个人的面板（我：我的知识数、在学、课程列表、各领域覆盖、最近学习；别人：公开知识、共同课程、各领域覆盖、「与我对比」），同时把星图切换成以这个人为中心的布局（§10.4）。
- 再点同一个头像、点空白处或按 Esc：回到默认布局，面板关闭。按住 Shift 点第二个人：两人对比。
- 面板右上角有收起按钮，收起后留一个小条，点开恢复；面板**只由用户收起或打开，永远不随缩放、聚焦或选课程自动变化**。
- 删除：右下角「定位到我」按钮、「高亮我的」开关、常驻的「我的知识」大框。
- 右下角只保留：缩小、缩放百分比（放大变大、缩小变小）、放大、复位视角。

### 10.4 以人为中心的布局

- 这个人的知识被拉到中心，聚成紧凑的核心，外圈用人物色环标记；其他知识按与核心的关系远近一圈圈向外排（一步相连在内圈，越远越外），尽量保持在默认布局中的方向，所以领域依然可辨。
- 非这个人的知识保持可见（约 50% 亮度），连线更淡；缩小后能直接看出「我的核心在全局里的位置和覆盖面」。
- 布局是「图结构 + 人物集合」的确定函数，可缓存；切换时所有节点平滑移动（600ms），镜头同时调整。形成之后在这个布局上自由旋转、缩放，不再重排。
- 两人对比：两人知识的并集作为核心，节点外圈按人物色分段，面板显示两人各领域覆盖。
- 别人的知识只使用服务端授权给当前用户的数据；没有社交后端前按功能预览接入（§2）。

### 10.5 档案里的选中与课程聚焦

- **点一个知识**：它本身、相连的边和一步内的邻居高亮并显示标签，其他节点降到约 20% 亮度；右侧滑出详情侧边栏（所属领域与主题、谁已学、相邻知识、出现在哪些课程），画面左移让出侧边栏。点空白处或按 Esc 取消。悬停只做轻量预览（标签 + 相连边）。
- **选课程**（从个人面板的课程列表）：
  - 这门课的知识（就是星图里的同一批节点）从原位置移动到一个正对镜头的平面上，按课程的 ELK 坐标排开；每章一个半透明章节区域，章节标题在区域上方。**不另外叠一层平面图。**
  - 其余星图留在平面后方，约 40% 亮度；课程知识连向课程外知识的边保持淡淡可见。
  - 悬停课程里的某个知识：它连向全局的边、以及连到的全局知识一起变亮并显示名称。
  - 顶部出现课程条：课程名、进度、「点空白处返回星图」提示、「进入课程」。
  - 个人面板不关闭；平面自动缩放并让到面板右侧，完整可见。
  - 点空白处或按 Esc：课程节点飞回原位，恢复星图。点「进入课程」或点课程里的知识：进入课程页（同一场景继续，不重新加载）。

### 10.6 课程页：两个视图

- 顶部只有「课程树」「路线」两个标签。技能树、实训树、能力模型不再是分开的标签页。
- 左上：「← 档案」（回到 §10.5 的课程平面）、课程名、已学数与当前知识。底部：图例（已学 / 在学 / 待学，合计等于课程知识数；当前、目标为标记）。

### 10.7 「课程树」视图

- **技能树与实训树互为倒影**（照旧版课程图的叠卡效果）：每张知识卡正下方叠着它对应的实践卡（向右下错开约 14px、虚线、半透明，只露出边缘）；没有对应实践的位置显示虚线的「暂无对应实训」。点「切换到实训树」：两层交换前后（400ms），实践卡变成实体、知识卡变成倒影；再点切回。切换不重排、不改镜头；打开的详情跟随切换到对应侧面。
- **项目能力模型在后方**：课程外的前置能力放在支撑它的课程知识正后方更深的平面；正面时几乎看不见，拖拽旋转后显现，虚线连到前面的知识。可 360° 旋转；双击空白处回到正面。旋转后若卡片重叠，较远的卡片暂时收成点。
- **我的路线默认显示**：沿路线经过的知识画一条带流动光点的光带，知识卡左侧标步骤序号，当前步有「你在这里」。工具条里可关闭。
- **点一个节点**（知识 / 实践 / 前置能力）：无关卡片变暗；它的前后依赖、对应实践、前置能力、路线上前后两步保持高亮，相关连线加亮；不在路线上的选中会让路线光带变淡。右侧直接滑出详情侧边栏（不再是小卡片）：知识显示学什么、关联实践、前置、我的学习证据和主按钮；实践显示要做什么、覆盖的知识、提交给谁；前置能力显示是否已掌握、支撑哪些知识。侧边栏里的条目可以点击跳转。点空白处或按 Esc 关闭。
- **近看**：卡片放大到一定程度时显示行动行（微学习用时、实践编号、资料页码）。章节标题、卡片、标签任何时候不重叠。
- **调整路线**：同一批节点压平成三列（已获得 → 中间能力 → 目标，列内按依赖深度排列、过多时分子列），当前路线为主色流动光带，预览路线为绿色虚线；必须经过 / 不经过、预览、采用沿用现有服务端校验。点「完成」回到 3D。

### 10.8 「路线」视图（闯关式）

- 竖向蜿蜒的路径，参照多邻国 / Brilliant：每一步是一个立体圆盘，已完成为对勾，当前步发光并带图标，未开始为灰色；圆盘旁写知识名、状态与用时；章节是路径上的横幅；当前步下方有「开始」卡片。
- 打开时自动滚到当前步。点圆盘打开同一个详情侧边栏。右上角「调整路线」进入 §10.7 的压平编辑。
- 路线视图里**不再另开一个列出同样步骤的侧边栏**。

### 10.9 验收方式（P3R / P4R）

- 除逐屏对照外，验收人按本节逐条亲手操作：旋转、三层缩放、点人与再点还原、Shift 对比、面板收起与展开、人与分享、点节点与点空白、选课程与悬停、进入课程、倒影切换、旋转看能力层、双击回正面、点节点看侧边栏、路线视图、调整路线与完成、返回档案。任何一条不符即打回。
- 性能：默认与以人为中心两种布局下，档案在本地最大数据量旋转 ≥ 50fps（硬件 GPU）；以人为中心的布局首次计算 < 300ms（超出则放到 Web Worker）。
