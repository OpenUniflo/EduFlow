# EduFlow 新版设计规格（重建画布用，所有画板共同遵守）

## 产品与原则
EduFlow：以共享知识图谱为核心的 AI 学习平台（知识节点、课程、能力、个人路线、微学习、实践、工作流）。
1. 一个助手、一个会话：首页的大对话 = 其他页面左下角小助手，同一会话。
2. 对象原地打开，不跳页；单击查看、打开即操作；任何对象可交给助手；改变状态一律「提议 → 预览差异 → 确认」。
3. 对话卡片可做轻量单步操作（简单微学习选择/填空）；多步/编辑/需要空间 → 工作区或沉浸。
4. 图形化：知识、能力、课程、路线用空间与图形表达，不只靠列表。

## 导航（左侧窄栏 64px，图标 + 短标签，清透玻璃风格）
首页 · 学习地图 · 作品 · 记录；按权限：教学（教师）、管理（管理员），两者分别授予。底部头像/设置。

## 助手
- 首页：对话本身是主画面（居中，最大宽 760）。
- 首页以外所有页面：**左下角小助手**圆钮（清透玻璃，靛紫图标，有任务时状态点），点开从左下向上展开常规玻璃面板（约 400×560），顶部「在首页继续」「收起」；输入框自动带上下文胶囊（可删）。始终最顶层，不被遮挡。
- 就地操作：助手提议以幽灵差异显示在画布上（新增=虚线绿、删除=红色划线、修改=琥珀），面板里列变更项，逐项/全部接受，可撤销。学习进度/能力状态助手只能解释不能改。

## 学习地图
- 默认：我的知识版图（已学/在学 + 周边可探索节点，力导布局视觉：节点自由分布但不重叠）。
- 课程聚焦：点课程 → 课程节点飞行重排为整齐的章节分层结构（开放式：章节名是区域注记，无方框），其余节点淡出 25%。Esc/返回倒放。悬停不改变地图。
- 左上课程浮层（常规玻璃，可收成胶囊）：搜索框；无输入时「正在学习」（进度环、下一步；个人课程带“个人”标记；“草稿 N” 一行）+「推荐」（3–5 门，带理由）；输入后变搜索结果（课程/知识分组）。点课程 → 该行原地展开摘要（章节数、时长、覆盖率）+「进入课程」（仅已加入/我创建）或「加入学习」。
- 助手搜课/建课：结果是对话卡片（搜索结果卡、课程创建简报卡）。动画：拉远到全局星图缓慢旋转 → 真实结果节点依次亮起 → 减速锁定 → 重排成课程结构（建课时前置知识沿真实前置关系逐层点亮）。用户动过地图则不抢镜头，提示“已找到 · 定位”。
- 「进入课程」→ 课程沉浸界面：课程结构放大铺满，浮层淡出；面包屑“学习地图 › 课程名”；视角：技能树 / 实训树 / 路线；抽屉显示详情。路线 = 地铁线（靛紫粗轨道，站点，“你在这里”，站点挂行动胶囊「微学习 · 8 分钟」「实践」），与细知识关系线明显区分；建议新路线 = 灰色虚线幽灵线 + “+2 步 / −1 步”标注，预览后「确认采用」。
- 能力视角颜色：已获得 #3B82F6、目标 #22C55E、待学 #9CA3AF；当前路线方向流光。

## 首页
- 今日区：问候；「继续学习」卡（课程名、导航给出的下一步、迷你地铁线剪影、主按钮）；迷你学习地图（最近点亮节点）；可选小组件（本周学习天数）。
- 对话：S/L 卡展示；简单微学习在对话卡片内作答（选项、规则判定反馈条、「为什么？」「下一题」）；复杂内容在右侧工作区（对话保持左侧）。
- 完成微学习：卡片收成摘要“已完成 · 状态更新为「已学习」”（不是掌握），迷你地图对应节点点亮。

## 作品 / 记录 / 教学 / 管理
- 作品：我的工作流（草稿/模板）、实践成果与评价。工作流在沉浸模式编辑（画布 + 节点配置 + 测试运行；“测试运行不会提交实践，也不会更新能力状态”）。
- 实践提交：统一确认组件（提交内容摘要、提示“提交后不可修改，评价不等于掌握”）→ AI 评价（通过/需修改 + 依据）。
- 记录：顶部学习活动热力图（GitHub 风格，靛紫色阶），下方按日期分组时间线，类型/课程/时间筛选，点击行内展开并链回任务/成果/对话。
- 教学：课程管理/任务与作业/学员进展/提交与审核，表格 + 批量操作；课程创作 = 分阶段流程（需求 → 知识范围 → 课程结构 → 学习资源 → 预览 → 发布）在沉浸中进行。
- 管理：用户/组织/角色与权限/系统配置/知识领域。
- 教学与管理表格页也在同一外壳内，左下小助手同样存在。

## 视觉（定稿：PaletteCompare.dc.html 最上方「A 优化版」段）
- 直接**复用该段的 CSS（.lg-regular / .lg-clear、厚边伪元素、透镜位移滤镜写法、环境光背景、节点三层、路线样式）**，复制到每个画板的 <style> 与隐藏 SVG defs 中。
- 底：连续环境光（靛紫→雾蓝→浅青，超大低对比渐变，无色斑）；页面 #F7F8FA 基调；正文 #0F172A/#111827，次要 #6B7280，边框 #E5E7EB。
- 品牌主色 靛紫 #6D5DF6（主按钮、你在这里、路线轨道）。领域色 8 色：#E07A7A #E0A060 #C9B24A #6FBF73 #4FB8B0 #5B9BE0 #8C7BE0 #CF79C0。
- 节点：普通 = 实心 + 1.5px 白描边无光晕；当前/目标/悬停 = 光晕（全画面 ≤3 个发光）；淡化节点 25% 纯色。知识连线细实线 #CBD5E1。
- 玻璃：大面板 .lg-regular（重模糊，文字稳定），小控件 .lg-clear（强折射）；圆角同心（面板 24、按钮 14）。
- 动效说明可用小字标注；prefers-reduced-motion / prefers-reduced-transparency 回退必须有。
- 文案全中文、真实合理（课程示例：AI Agent 开发基础、LangGraph 实战、我的 RAG 路线；知识示例：模型基础、提示工程、工具调用、状态管理、智能体编排、检索增强）。用户名用“小林”。

## 边界（不得违反）
- 地图只画真实节点/关系，不画假节点/假连线/领域区块。
- AI 不决定下一步、不直接修改课程/路线/学习状态；一切改动需预览确认。
- 微学习完成=已学习，不是掌握；测试运行不提交；提交≠掌握。
- 路线连线=执行顺序，视觉区别于知识关系线。
- 未登录：可浏览全局星图和公开课程，助手显示锁定说明与登录入口（可在一张画板角落体现）。

## 画板文件格式（严格）
参考同目录现有 `.dc.html`（如 PaletteCompare.dc.html）：
`<!doctype html><html lang="zh-CN"><head><meta charset="utf-8"><title>…</title><script src="./support.js"></script></head><body><x-dc><helmet><style>…</style></helmet> 内容 </x-dc><script type="text/x-dc" data-dc-script data-props='{"$preview":{"width":1440,"height":H}}'>class Component extends DCLogic { renderVals(){ return {}; } }</script></body></html>`
- 根容器流式 `width:100%; min-height:Hpx`，不要固定总宽；<900px 时合理堆叠。
- 只用内联 CSS/SVG，可用 data URI；无外部 URL。
- 可访问性：真实 button/a、aria-label、装饰 SVG aria-hidden。
- 不删除任何文件，不做 git，不修改 canvas.json（除非任务明确要求）。

# 第二版增补（2026-10-28 确认，覆盖上文冲突处）

## A. 3D 空间
- 学习地图与课程共用一个 3D 空间，**自由旋转**（拖拽环绕、滚轮缩放）。节点 3D 坐标固定，所有视角变化只动镜头，不重排。
- 坐标：X = 课程层级顺序（ELK 计算），Y = 层内展开与章节区域，Z = 离已获得能力的纵深（课程节点 z=0；课程外灰色中间能力在后；已获得能力（蓝）最深，像地基）。
- **默认姿态**：聚焦课程 / 进入课程时镜头摆到正面（正交），后方能力层被课程平面挡住（淡到 ~10%），看起来就是整齐技能树。
- 看完整能力模型：按钮「能力模型」→ 镜头自动环绕到斜侧姿态；或用户直接拖转。另有「回正」按钮回到正面。
- 渲染：正面姿态与编辑用 React Flow + ELK；一旦离开正面切到 three.js 场景（同一套坐标，正面时正交镜头与 React Flow 像素重合，无缝交接）。进入编辑自动回正。
- 文字标签始终面向屏幕；星图空闲时缓慢自转，悬停/选中暂停，手动操作后有宽限期；减少动态 → 无环绕动画直接切；WebGL 不可用 → 2D 树/列表回退。

## B. 实训树 = 课程的倒影
- 每个节点是双面卡：正面知识，背面该节点的实训组。「技能树 ⇄ 实训树」= 按层从左到右依次翻牌（~600ms），位置不动；连线同时由 KnowledgeEdge 换成 AssignmentDependency。
- 斜视角下可见倒影：课程平面下方玻璃地面上映出实训层，竖细线 = AssignmentCoverage；跨多个知识点的实训显示为横跨的宽卡。

## C. 学习地图：只有一张星图
- 取消独立的「我的版图」。星图 = 当前用户可见的全部知识（全局 + 个人可见；个人知识点带小标记）。
- 「我的」是子集标记：学过/在学节点加状态圆环（在学半环），领域色不变；其余节点略淡。
- 右上「我的」按钮：镜头飞到并框住我的子集（只动镜头）；可选开关「只看我的」把其余淡到 15%。
- 无学习记录：无圆环；点「我的」原地小提示「还没有学习记录」+「找一门课程」「问助手」，镜头不动。

## D. 课程创建（6 阶段，原地搭建）
1 需求（助手对话 → 课程创建简报卡）→ 2 知识范围（星图上目标绿亮、前置沿真实前置逐层点亮、点选加入/排除、提示已有课程覆盖率）→ 3 课程结构（节点飞入草稿平面、AI 建议章节为幽灵差异、拖动换章、违反前置当场拒绝）→ 4a 学习资源（**知识面**：每节点「微学习」「资料」资源位，空位空心，缺口提示不阻止发布）→ 4b 实践设计（**翻到实训面**：实训任务及覆盖、实训依赖、章节成果、结课项目）→ 5 学员视角预览 → 6 发布校验清单（阻塞的结构问题 / 不阻塞的资源缺口）。
- 顶部阶段条可回退；每步都是 提议 → 预览差异 → 校验 → 确认。个人课程同流程，4a/4b 可跳过，「发布」= 开始学习（仅自己可见）。

## E. 实践审核
- 审核方式是课程级服务端配置：AI 自动审核 / AI 初审 + 教师复核 / 教师审核。不强制教师。
- 提交 → 服务端 AI 依据评分标准评价 → 通过 / 需修改，给出逐条依据；学员可申诉转教师。
- 教学端「审核」页：待审队列 + 左侧提交内容（代码/文件/运行记录/历史版本）+ 右侧评分标准、AI 结论与依据、教师评语与裁定；AI 自动审核的课程这里作为抽查与申诉处理。

## F. 状态画面（替代原「空/失败/无结果」清单）
- 空：作品为空、记录为空（地图无空状态，见 C）。
- 无结果：搜课/助手找不到 → 说明原因 +「换个说法」「用这个目标创建个人课程」。
- 失败：就地错误条，说明哪步失败、是否已保存 +「重试」；3D 加载失败回退 2D。

## G. 需修订的 AGENTS 规则（写 ADR）
- 课程图渲染：补“能力视角可投影到 3D 场景，坐标来源仍为 ELK”。
- Global/Personal Atlas：合并为“可见知识星图 + 我的子集标记”，替代 Personal Atlas 单独定义。
- 实践审核：允许课程级 AI 自动审核作为 accepted 来源（服务端、版本化 PerformanceResult）。

## H. 学习地图 = 我的档案（2026-10-29 确认，覆盖 C 中冲突处）
- 学习地图两个场景，同一套 3D 坐标：**我的（默认）** / **全局**。右上分段切换「我的 · 全局」。切换只淡入淡出其余节点 + 镜头拉远/拉近，不重排。
- 我的场景：星图只显示我已学/在学节点 + 一跳可探索节点（淡），用它们在全局中的原位置；左上浮层 = 档案卡（可折叠：头像、简介、按领域能力概览小条、本周学习 5 天；「分享」「可见性」「以他人视角预览」）+ 正在学习 + 推荐 + 搜索框 + 社交动态（关注的人近况，≤3 条，可收起，只有自己可见）；我当前在学节点旁显示同行者小头像簇。
- 自动切到全局：搜索、助手找课/建课（旋转星图动画）、聚焦的课程含我范围外节点。全局场景左上有「回到我的」。
- 新用户无学习记录 → 默认进入全局 + 引导“从一个目标开始”；学完第一个节点后默认改为我的。未登录只有全局。
- 他人档案：同一场景换成对方公开子集与档案卡（「关注」「和我对比」）；对比 = 三色叠加（都学过 / 只有他 / 只有我），他有我没有的节点可「我也想学」→ 交给助手。分享链接打开即他人场景（/map?u=xiaolin）。
- 节点抽屉「同行者」：正在学 23 · 已学过 140；头像仅限关注的人与同课程公开档案者，≤5 + “+18”；<5 人只显示“少于 5 人”；操作：查看档案、关注（私信/小组后续）。
- 隐私：默认不公开；范围 仅自己 / 拿到链接的人 / 本组织（本版不做互联网公开）；可按课程、作品、热力图、能力概览分项开关；永不展示分数、失败尝试、对话、AI 评价细节、未完成提交。分享 = 快照卡片 + 可撤销链接。
- 导航不新增入口；导航底部头像 → 学习地图我的场景；头像菜单含「设置」。

## I. 档案（2026-10-29 确认，覆盖 H 中冲突处）
- 导航「学习地图」改名「档案」；面包屑“档案 › 课程名”；首页“在档案中打开”。场景仍为「我的 · 全局」。
- 对比：不设对比面板。档案顶部（或档案卡下）一排人物胶囊（头像 + 专属颜色 + ×），「+ 添加对比」从关注的人中选，最多 4 人（含我）。星图节点填充仍是领域色；节点外圈改为**分段环**：每段一个人的颜色，有就亮、没有就空（灰虚段）；所有人都有 = 完整闭环。人物色用与领域色区分的一组（如 我 靛紫 #6D5DF6、橙 #F59E0B、青 #06B6D4、玫红 #EC4899），环外侧小刻度标注。点人物胶囊 = 只高亮此人拥有的节点；悬停节点 = 小卡列出谁有（已学/在学）。他人只显示其公开子集。他有我没有的节点悬停卡含「我也想学」。
- 可见性与分享：带遮罩的大浮窗（常规玻璃，约 880×620，居中，背景星图压暗模糊），从档案卡「分享」或「可见性」打开；左栏设置（范围、分项开关、永不展示清单），右栏实时预览（他人视角缩略星图 + 分享卡片 + 链接 复制/撤销）；底部「完成」。不再做常驻面板。

## J. 对象外壳与首页为主（2026-10-29 确认，覆盖之前冲突处）
- 原则：以首页对话为主。任何对象（实践任务、微学习、课程、工作流、知识节点、人、档案）在任何地方打开都用**同一个对象外壳**，四种尺寸：卡片 S（对话内：标题、状态、一个主操作）/ 卡片 L（对话内：加一个关键内容区，可单步操作）/ 侧面板（首页右侧工作区约 45%，完整内容可操作；档案节点抽屉、课程沉浸抽屉、教学审核详情、沉浸检查器也是它）/ 沉浸（全屏，对话收成左下小助手，加专门编辑区）。
- 外壳固定：头部（类型图标、标题、上下文胶囊、状态徽标；右上固定「展开/收起/沉浸/关闭」）；内容分区顺序固定，尺寸越小从后往前省略；底部固定操作栏，主按钮右下；外层圆角 24、常规玻璃、统一间距。
- 实践：卡片 S「开始实践」→ 侧面板自动展开（可收回卡片）→ 工作流类可进沉浸（面板变为画布右侧检查器）。侧面板分区：要求（一句话目标、交付物清单勾选、评分标准可折叠）→ 我的提交草稿（附件、仓库链接、运行记录，可添加/删除/写说明）→ 详情（折叠：覆盖知识、前置实训、历史尝试、审核方式）。对话负责思考、提示、AI 自查；AI“加入提交”建议在面板里显示为待确认变更；对话不能直接提交。
